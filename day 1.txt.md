### 1. What I Learned

**1. Terminal Emulator**

A terminal emulator is a graphical application that allows users to interact with the shell by entering commands.

**2. Shell**

A shell is a command interpreter that understands the commands entered by the user and executes them.

### 2. Linux Commands

| Command | Meaning | Purpose |
|---|---|---|
| `ls` | List | Displays existing files and folders |
| `cd` | Change Directory | Moves from one directory to another |
| `mkdir` | Make Directory | Creates a new directory |
| `rmdir` | Remove Directory | Deletes an empty directory |
| `pwd` | Print Working Directory | Displays the current directory path |
| `rm` | Remove | Deletes files or directories (with appropriate options) |
| `cd ..` | Parent directory navigation | Moves one directory level backward |
| `cd ~` | Home directory navigation | Moves directly to the user's home directory |

### 3. Important Concepts

- **`~` (Tilde):** Represents the current user's home directory.
- **`..` (Double dot):** Represents the parent directory.
- **Directory:** Another name for a folder in Linux.
- **`mkdir`:** Used to create directories.
- **`rmdir`:** Used to remove empty directories.

### 4. Practical Commands I Practised

Create a folder:
```bash
mkdir Engineer180
```

Enter the Downloads folder:
```bash
cd ~/Downloads
```

List files and folders:
```bash
ls
```

Check the current location:
```bash
pwd
```

Move one directory backward:
```bash
cd ..
```

Delete an empty folder:
```bash
rmdir Engineer180
```
