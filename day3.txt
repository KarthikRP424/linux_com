LINUX LEARNING JOURNEY
========================
DAY 3 – BASH, ENVIRONMENT VARIABLES AND FILE COMMANDS

1. BASH

Full Form: Bourne Again Shell

Definition:
Bash is a command-line interpreter (shell) that allows users to communicate with the operating system using commands.

Example:
echo "Hello Linux"

2. ECHO

Definition:
echo is a command used to display text or variable values in the terminal.

Example:
echo "Good Morning Karthik"

Output:
Good Morning Karthik

3. CREATING OUR OWN ENVIRONMENT VARIABLE

Command:
export MY_PATH="KARTHIK"

Definition:
- export creates an environment variable or makes an existing variable available to child processes.
- MY_PATH is the variable name.
- KARTHIK is the stored value.

To display the variable:
echo $MY_PATH

Output:
KARTHIK

4. PWD – PRINT WORKING DIRECTORY

Command:
pwd

Definition:
Displays the absolute path of the current working directory.

Example Output:
/home/karthik

5. LS COMMAND

A. ls -a

Definition:
Displays all files and directories, including hidden files.

Note:
Hidden files usually start with a dot (.).

B. ls -l

Definition:
Displays files and directories in long-list format.

It provides:
- File permissions
- Number of links
- Owner
- Group
- File size
- Modification date
- File name

C. ls -la

Definition:
Displays all files, including hidden files, in long-list format.

6. CAT – CONCATENATE

Definition:
cat stands for Concatenate.

It is used to:
- Display file contents.
- Combine multiple files.
- Create files and write content using redirection.

A. Create a file:

Command:
cat > Hello

Type:
Good morning Karthu

Press Ctrl + D to finish and save.

B. Display file contents:

Command:
cat Hello

Output:
Good morning Karthu

Note:
The > operator creates a file or overwrites its existing contents.

The >> operator appends new content without removing existing content.

7. PWD AND DIRECTORY NAVIGATION

cd = Change Directory

Examples:

cd ~
Go to the home directory.

cd ..
Move one directory level up.

cd -
Return to the previous working directory.

cd ~/Downloads
Open the Downloads directory.
